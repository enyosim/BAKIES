# BAKIES 🧁🐾

Juego y app web interactiva de coleccionismo estilo **Gacha / Álbum de Stickers** ambientada en un universo de repostería viva.

## ✨ Características
- **Splash Screen:** Pantalla de carga con logo flotante, barra de bastón de caramelo animada y mensajes dinámicos de pastelería.
- **Apertura de Sobres (Gacha):** Animación cuadro a cuadro (*frame-by-frame*) del sobre rasgándose de derecha a izquierda con efectos de confeti y partículas por código.
- **Álbum de Stickers:** Clasificación por especies con nombres únicos (`Puppcake`, `Tartle`, `Donubear`, `Cinnashell`, etc.) y variantes numeradas (`#001`, `#002`, etc.).
- **Diseño Visual:** Estética 100% estilo *Cookie Run: Kingdom* en 2D Flash cel-shading, fondos pastel suaves y rejilla punteada.
- **Persistencia Local:** Todo tu progreso y colección se guardan automáticamente en el navegador.

Abre directamente `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, etc.).
